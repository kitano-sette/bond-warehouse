ภาพใหญ่

ตราสารหนี้ช่วย กระจายความเสี่ยง สร้าง กระแสเงินสดรับที่มีเสถียรภาพ และช่วย บริหารความเสี่ยงจากการเปลี่ยนแปลงของอัตราดอกเบี้ย

💡 ภาพจำ

ดอกเบี้ยขึ้น → ราคาพันธบัตรลง; และถ้าดูเรชั่นสูง ราคาจะไวต่อการเปลี่ยนแปลงมากกว่า

1.2 Total Return Approach

Total Return Approach เป็นการบริหารเชิงรุกที่อาศัยการคาดการณ์การเปลี่ยนแปลงปัจจัยเสี่ยงที่ทำให้ราคาตราสารหนี้เปลี่ยน โดยเอกสารแบ่งเป็นกลยุทธ์ที่อิง Duration, Yield Curve, Spread และ Volatility

Duration Strategy

เมื่อคาดดอกเบี้ย ขึ้น → ลด Duration; เมื่อคาดดอกเบี้ย ลง → เพิ่ม Duration

⚠️ อย่าสับสน

Duration เป็นตัวชี้ความไวของราคาตราสารหนี้ต่ออัตราดอกเบี้ย ไม่ใช่กำไรที่รับประกัน

Yield Curve Strategy

พิจารณารูปร่างของเส้นอัตราผลตอบแทนและเลือกโครงสร้าง Bullet / Barbell / Ladder ให้สอดคล้องกับมุมมองต่อเส้นอัตราผลตอบแทน

Steepening = ความชันเพิ่มขึ้น; Flattening = ความชันลดลง ตามแผนภาพต้นฉบับหน้า 13

สูตรการเปลี่ยนแปลงราคาตราสารหนี้

ΔP/P ≈ −D × Δy
ΔP/P ≈ [−D × Δy] + [½ × Convexity × (Δy)2]

D = ดูเรชั่น, Δy = การเปลี่ยนแปลงของผลตอบแทน, Convexity = คอนเวคซิตี้; เปอร์เซ็นต์ต้องแปลงเป็นทศนิยม เช่น 1% = 0.01

1.3 Cash Flow Matching

เป้าหมายคือสร้างกระแสเงินสดจากตราสารหนี้เพื่อจ่ายภาระผูกพันในอนาคต มี 2 แนวทางหลักคือ Immunization Strategy และ Cash Flow Matching Strategy

💡 จำให้แม่น

Immunization เน้น Duration ของสินทรัพย์ให้เท่ากับระยะเวลาของภาระผูกพัน; Cash Flow Matching เน้นจับคู่กระแสเงินสดรับกับกระแสเงินสดจ่าย

1.4 Unified Approach

แยกการลงทุนตามความเสี่ยงและความชำนาญ และเทียบผลตอบแทนกับ Benchmark โดย Beta Portfolio มุ่งสร้างผลตอบแทนให้เท่าตลาด/Benchmark ส่วน Alpha Portfolio มุ่งสร้างผลตอบแทนให้มากกว่าตลาด/Benchmark

📝 วิธีตัดตัวเลือก

“เท่ากับตลาด/Benchmark” ให้คิด Beta; “มากกว่า Benchmark” ให้คิด Alpha

1.5 ปัจจัยเลือกกลยุทธ์

  • ลักษณะผลตอบแทนที่ต้องการในอนาคต
  • ความเสี่ยงที่เข้าใจและยอมรับได้
  • มุมมองต่อความมีประสิทธิภาพของตลาด

🔥 เก็งบทที่ 1 — 5 ประโยคที่ต้องท่องได้

  1. คาดดอกเบี้ยขึ้น → ลด Duration | คาดดอกเบี้ยลง → เพิ่ม Duration
  2. Parallel เล็ก & Steepening → Bullet ชนะ | Parallel ใหญ่ & Flattening → Barbell ชนะ
  3. Immunization = Duration สินทรัพย์ = ระยะเวลาภาระผูกพัน
  4. Multiple Liabilities: PV สินทรัพย์ > PV หนี้สิน + การกระจาย Duration กว้างกว่า
  5. Beta = เท่าดัชนี (systematic เท่านั้น) | Alpha = ชนะดัชนี (systematic + idiosyncratic)

1.2.2 ตัวอย่างและการประยุกต์ใช้กลยุทธ์ในการบริหารกลุ่มหลักทรัพย์ตราสารหนี้

1) กลยุทธ์ที่อิงกับดูเรชั่น (duration)

ดูเรชั่นคือค่าที่ใช้บอกถึงการเปลี่ยนแปลงของราคาตราสารหนี้ เมื่ออัตราดอกเบี้ยมีการเปลี่ยนแปลง การบริหารกลุ่มหลักทรัพย์ตราสารหนี้โดยใช้กลยุทธ์ที่อิงกับดูเรชั่นอาศัยหลักความสัมพันธ์ระหว่างราคาตราสารหนี้กับการเปลี่ยนแปลงอัตราดอกเบี้ยในตลาด โดยนักลงทุนจะพยายามคาดคะเนทิศทางของอัตราดอกเบี้ยในตลาดว่าจะเพิ่มขึ้นหรือลดลง เมื่ออัตราดอกเบี้ยในตลาดปรับเพิ่มขึ้นราคาของตราสารหนี้ที่มีการจ่ายคูปองในอัตราที่คงที่จะปรับลดลง ทำให้นักลงทุนจะขาดทุนด้านราคา ในทางกลับกัน หากอัตราดอกเบี้ยในตลาดปรับลดลงราคาของตราสารหนี้จะปรับสูงขึ้น นักลงทุนจะมีโอกาสในการทำกำไรจากการขายตราสารหนี้

🎯 จำสั้น

  • Duration = ตัวเลขบอก ความไวของราคา ต่อการเปลี่ยนดอกเบี้ย
  • ดอกเบี้ย↑ → ราคาลง; ดอกเบี้ย↓ → ราคาขึ้น

🔥 เก็งข้อสอบ

กับดัก: ลืมใส่เครื่องหมายลบ หรือลืมแปลง % เป็นทศนิยม (0.5% = 0.005 ไม่ใช่ 0.5)

ผลกระทบของ Parallel Shift, Steepening และ Flattening ต่อ 3 โครงสร้าง ออกแน่นอน

ที่มา: หน้า 20

ผลกระทบจากการเปลี่ยนแปลงรูปร่างของเส้นอัตราผลตอบแทน (ทั้งแบบ parallel shift, steepening curve และ flattening curve) ต่อโครงสร้างทั้ง 3 แบบสามารถสรุปได้ดังนี้

  1. Inกรณีที่เส้นอัตราผลตอบแทนเปลี่ยนแปลงแบบขนาน โดยมีการเปลี่ยนแปลงไม่มาก อัตราผลตอบแทนจากโครงสร้างแบบบุลเล็ต > อัตราผลตอบแทนจากโครงสร้างแบบบาร์เบล
  2. Inกรณีที่เส้นอัตราผลตอบแทนเปลี่ยนแปลงแบบขนาน โดยมีการเปลี่ยนแปลงที่ค่อนข้างมาก อัตราผลตอบแทนจากโครงสร้างแบบบาร์เบลจะเปลี่ยนแปลงสูงที่สุด
  3. Inกรณีที่เส้นอัตราผลตอบแทนเปลี่ยนแปลงแบบชันขึ้น (steepening) อัตราผลตอบแทนจากโครงสร้างแบบบุลเล็ต > อัตราผลตอบแทนจากโครงสร้างแบบบาร์เบล
  4. Inกรณีที่เส้นอัตราผลตอบแทนเปลี่ยนแปลงแบบลาดลง (flattening) อัตราผลตอบแทนจากโครงสร้างแบบบาร์เบล > อัตราผลตอบแทนจากโครงสร้างแบบบุลเล็ต

🎯 จำสั้น

  • Parallel เล็ก → Bullet ชนะ; Parallel ใหญ่ → Barbell
  • Steepening → Bullet ชนะ; Flattening → Barbell ชนะ
  • สรุป: Bullet เหมาะเมื่อ Parallel เล็ก & Steepening, Barbell เหมาะเมื่อความผันผวนมาก & Flattening

เฉลย: Bullet > Barbell

กับดัก: ข้อ 2 เขียนว่า "เปลี่ยนแปลงสูงที่สุด" ไม่ได้แปลว่า "ดีที่สุด" เสมอไป — หมายถึงไวที่สุด (จาก Convexity สูง) ถ้าดอกเบี้ยลงแรงจะกำไรมากสุด แต่ถ้าขึ้นแรงก็ขาดทุน...ไม่ใช่ เพราะ Convexity ช่วยทั้งสองทาง จำว่า ผันผวนแรง = Barbell ได้เปรียบ

ตัวอย่าง 1-1 + สูตรการเปลี่ยนแปลงราคาตราสารหนี้ สูตรออกแน่

ที่มา: หน้า 21

ตัวอย่างที่ 1-1 สมมติว่าหลังจากนักลงทุนสร้างกลุ่มหลักทรัพย์ตราสารหนี้ที่ใช้โครงสร้างแบบบุลเล็ต และเส้นอัตราผลตอบแทนเปลี่ยนแปลงแบบชันขึ้น (steepening) โดยอัตราผลตอบแทนของพันธบัตรรัฐบาลอายุ 2 ปี ปรับลดลง 1% และอัตราผลตอบแทนของพันธบัตรรัฐบาลอายุ 8 ปี ปรับเพิ่มขึ้น 1% และอัตราผลตอบแทนของพันธบัตรรัฐบาลอายุ 5 ปีไม่เปลี่ยนแปลง ผลกระทบต่อกลุ่มหลักทรัพย์ตราสารหนี้เป็นดังนี้

% การเปลี่ยนแปลงราคาตราสารหนี้ = −ดูเรชั่น × การเปลี่ยนแปลงของผลตอบแทน
% การเปลี่ยนแปลงราคาตราสารหนี้ = [−ดูเรชั่น × Δy] + [½ × Convexity × (Δy)2]

🎯 จำสั้น

  • สูตร: ΔP/P ≈ −D × Δy (หรือรวม Convexity สำหรับความแม่นยำสูง)
  • Steepening: Yield 2 ปีลง 1% + 8 ปีขึ้น 1% + 5 ปีคงที่

🔥 เก็งข้อสอบ

คิดตาม: Bullet (5 ปี) ใน Steepening นี้ราคาเปลี่ยนเท่าไร

Yield 5 ปี ไม่เปลี่ยน (Δy = 0) → ΔP/P = −4.1 × 0 = 0% ขณะที่ Barbell ขา 2 ปีกำไร (+1.9%) แต่ขา 8 ปีขาดทุน (−6.4%) → เฉลี่ย ≈ −2.25% → Bullet ชนะ ✔ ตรงกับหน้า 20 ข้อ 3

ตัวอย่าง 1-2 + สูตรการเปลี่ยนแปลงราคาตราสารหนี้ สูตรออกแน่

ที่มา: หน้า 22

ตัวอย่างที่ 1-2 สมมติว่าหลังจากนักลงทุนสร้างกลุ่มหลักทรัพย์ตราสารหนี้ที่ใช้โครงสร้างแบบบุลเล็ตและแบบบาร์เบล เส้นอัตราผลตอบแทนเปลี่ยนแปลงแบบลาดลง (flattening) โดยอัตราผลตอบแทนของพันธบัตรรัฐบาลอายุ 2 ปี ปรับเพิ่มขึ้น 1% และอัตราผลตอบแทนของพันธบัตรรัฐบาลอายุ 8 ปี ปรับลดลง 1% และอัตราผลตอบแทนของพันธบัตรรัฐบาลอายุ 5 ปี ไม่เปลี่ยนแปลง

% การเปลี่ยนแปลงราคาตราสารหนี้ = −ดูเรชั่น × การเปลี่ยนแปลงของผลตอบแทน
% การเปลี่ยนแปลงราคาตราสารหนี้ = [−ดูเรชั่น × Δy] + [½ × Convexity × (Δy)2]

🎯 จำสั้น

  • Flattening: Yield 2 ปีขึ้น 1% + 8 ปีลง 1% + 5 ปีคงที่
  • คู่กับหน้า 20 → Flattening Barbell ชนะ

🔥 เก็งข้อสอบ

คิดตาม: Barbell ใน Flattening นี้

ขา 2 ปี: −1.9 × 0.01 = −1.9% | ขา 8 ปี: −6.4 × (−0.01) = +6.4% → เฉลี่ย ≈ +2.25% ส่วน Bullet = 0% → Barbell ชนะ ✔

กลยุทธ์ที่อิง Spread และ Volatility กลาง

ที่มา: หน้า 23

3) กลยุทธ์ที่อิงกับ Spread และ Volatility

สำหรับกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารหนี้โดยใช้กลยุทธ์ที่อิงกับส่วนต่างของผลตอบแทนระหว่างประเภทตราสารหนี้ (spread) และความผันผวนของอัตราดอกเบี้ย (volatility) นักลงทุนจะไม่พยายามคาดคะเนปัจจัยที่มีผลกระทบต่ออัตราผลตอบแทนของพันธบัตรรัฐบาลอายุต่างๆ โดยตรง แต่นักลงทุนจะมุ่งเน้นบริหารความเสี่ยงที่เกิดจากความผันผวนโดยดูจาก Spread และ Volatility ระหว่างตราสารหนี้แต่ละประเภท

  • ตราสารหนี้ภาครัฐบาล (government bond) กับตราสารหนี้ภาคเอกชน (corporate bond)
  • ตราสารหนี้ปกติ (straight bond) กับตราสารหนี้ที่ผู้ออกมีสิทธิขอไถ่ถอนก่อนครบกำหนด (callable bond)

🎯 จำสั้น

  • Spread & Volatility: ไม่ทำนาย yield แต่บริหาร ส่วนต่าง ระหว่างประเภทตราสาร
  • คู่ที่สนใจ: รัฐ vs เอกชน, straight vs callable

🔥 เก็งข้อสอบ

คีย์เวิร์ดตัดตัวเลือก: "ไม่คาดคะเน yield โดยตรง" = Spread/Volatility strategy

กลยุทธ์ Cash Flow Matching หรือ Liabilities Funding Strategies เป็นกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารหนี้โดยหาเงินมาคืนให้แก่เจ้าของเมื่อครบกำหนดพร้อมผลตอบแทน วัตถุประสงค์หลักของกลยุทธ์นี้เพื่อให้นักลงทุนได้ผลตอบแทนเป็นกระแสเงินสดจากการลงทุนในกลุ่มตราสารหนี้เพื่อมาจ่ายภาระผูกพัน (liabilities) ในอนาคต

Immunization Strategy: หลักการ ออกแน่นอน

ที่มา: หน้า 25

อิมมูไนเซชั่น (Immunization) คือ การทำให้มูลค่าของกลุ่มหลักทรัพย์ปลอดจากความเสี่ยงจากการเปลี่ยนแปลงของราคาหลักทรัพย์ (market risk)

กลยุทธ์การลงทุนแบบอิมมูไนเซชั่น (Immunization Strategy) คือ การบริหารกลุ่มหลักทรัพย์ตราสารหนี้เพื่อลดความผันผวนของผลตอบแทนของกลุ่มหลักทรัพย์จากการเปลี่ยนแปลงของอัตราดอกเบี้ยในตลาด โดยมีหลักการที่สำคัญ คือ “การทำให้ดูเรชั่นของสินทรัพย์ในกลุ่มหลักทรัพย์ตราสารหนี้เท่ากับระยะเวลาคงเหลือของภาระผูกพัน”

🎯 จำสั้น

  • หลักการทอง: Duration สินทรัพย์ = ระยะเวลาภาระผูกพัน
  • เป้าหมาย: ป้องกัน market risk

🔥 เก็งข้อสอบ — ประโยคนี้ท่องคำต่อคำ

“ดูเรชั่นของสินทรัพย์ = ระยะเวลาคงเหลือของภาระผูกพัน”

ตัวอย่าง: บริษัทประกันมีภาระจ่ายใน 7 ปี ควรตั้ง Duration พอร์ตเท่าใด

เฉลย: 7 ปี (ไม่ใช่ maturity 7 ปี — ต้องเป็น Duration)

กับดัก: ตัวเลือกที่เขียนว่า "อายุคงเหลือของสินทรัพย์ = อายุภาระผูกพัน" คือ Maturity Method ไม่ใช่ Immunization ที่ถูกต้อง (ดูหน้า 28)

ลักษณะสำคัญ 3 ประการของ Immunization ออกบ่อย

ที่มา: หน้า 26

ลักษณะสำคัญ 3 ประการของกลุ่มหลักทรัพย์ตราสารหนี้ที่ใช้กลยุทธ์การลงทุนแบบอิมมูไนเซชั่น (Immunization Strategy) คือ

  1. สามารถระบุระยะเวลาการลงทุนได้แน่นอน
  2. ได้รับอัตราผลตอบแทนที่แน่นอนตลอดระยะเวลาการลงทุน
  3. มูลค่าของกลุ่มหลักทรัพย์ตราสารหนี้ปราศจากความเสี่ยงจากการเปลี่ยนแปลงของอัตราดอกเบี้ยในตลาดระหว่างการลงทุน

🎯 จำสั้น

  • 3 ลักษณะ: ระบุเวลาได้ / ผลตอบแทนแน่นอน / ไม่มีความเสี่ยงดอกเบี้ย

🔥 เก็งข้อสอบ

ท่องย่อ: "เวลาแน่ · ผลตอบแทนแน่ · ดอกเบี้ยไม่กระทบ"

ตัวอย่าง 1-3: Single Liability Immunization ฐานโจทย์

ที่มา: หน้า 27

กลยุทธ์ประเภท Immunization Strategy – กลยุทธ์การลงทุนแบบอิมมูไนเซชั่นสำหรับภาระผูกพันที่ต้องจ่ายเพียงครั้งเดียว (Single Liability Immunization Strategy)

ตัวอย่างที่ 1-3 ธนาคารพาณิชย์แห่งหนึ่งต้องจ่ายคืนเงินฝากจำนวน 1,000 บาท พร้อมดอกเบี้ยทบต้นในอีก 8 ปีข้างหน้า โดยรับประกันการจ่ายดอกเบี้ยที่อัตราร้อยละ 8 ต่อปี ธนาคารจะลงทุนในตราสารหนี้ ณ วันนี้ เพื่อจ่ายภาระผูกพันในอนาคต

🎯 จำสั้น

  • โจทย์: ฝาก 1,000 | ดอกเบี้ย 8%/ปี | จ่ายคืนใน 8 ปี

🔥 เก็งข้อสอบ

3 วิธี: Zero Coupon, Maturity และ Duration Method ออกบ่อย

ที่มา: หน้า 28

กลยุทธ์ที่ 1 Zero Coupon Method ธนาคารพาณิชย์จะลงทุนในตราสารหนี้ที่ไม่จ่ายดอกเบี้ยระหว่างงวด (zero coupon bond) อายุคงเหลือ 8 ปี จำนวน 1,000 บาท ที่อัตราดอกเบี้ย 8%

กลยุทธ์ที่ 2 Maturity Method ธนาคารพาณิชย์จะลงทุนในตราสารหนี้ที่จ่ายดอกเบี้ยเป็นงวด อายุคงเหลือ 8 ปี จำนวน 1,000 บาท อัตราดอกเบี้ย 8% จ่ายดอกเบี้ยปีละครั้ง

กลยุทธ์ที่ 3 Duration Method ธนาคารพาณิชย์จะลงทุนในตราสารหนี้ที่จ่ายดอกเบี้ยเป็นงวดที่มีดูเรชั่นเท่ากับระยะเวลาการลงทุน (matched duration method) ในกรณีนี้ กำหนดให้ธนาคารลงทุนในตราสารหนี้ที่จ่ายดอกเบี้ยเป็นงวด อายุคงเหลือ 10 ปี ดูเรชั่น 8 ปี จำนวน 1,000 บาท อัตราดอกเบี้ย 8% จ่ายดอกเบี้ยปีละครั้ง โดยจะขายตราสารหนี้เมื่อสิ้นสุดระยะเวลาการลงทุน ณ สิ้นปีที่ 8

🎯 จำสั้น

  • Zero Coupon: ลงทุน ZCB อายุ 8 ปี
  • Maturity: ลงทุนหุ้นกู้จ่ายคูปองอายุ 8 ปี
  • Duration: ลงทุนพันธบัตรอายุ 10 ปี Duration = 8 ปี แล้วขายปีที่ 8

🔥 เก็งข้อสอบ

  • ภาระใน 7 ปี = 19,487 | r = 10% → PV = 10,000
  • ลงทุน 2 ตัว: ZCB 3 ปี + Perpetuity

DZCB = อายุ = 3 ปี | Dperpetuity = (1 + r) / r = 1.10/0.10 = 11 ปี

3w + 11(1−w) = 7 → 11 − 8w = 7 → w = 0.50
→ ลงทุน ZCB 5,000 บาท + Perpetuity 5,000 บาท

  3. ขั้นตอนที่ 3: หาสัดส่วนการลงทุนในตราสารหนี้ทั้งสอง เพื่อให้ดูเรชั่นเฉลี่ยของกลุ่มสินทรัพย์เท่ากับดูเรชั่นเฉลี่ยของกลุ่มภาระผูกพัน
  4. ขั้นตอนที่ 4: บริษัทจะจัดพอร์ตการลงทุน

  • 4 ขั้น: Duration หนี้ → Duration เฉลี่ย → สัดส่วน → จัดพอร์ต

สมมติฐานของ Single Liability Immunization ออกบ่อย

ที่มา: หน้า 33

กลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารหนี้แบบอิมมูไนเซชั่นสำหรับภาระผูกพันที่ต้องจ่ายเพียงครั้งเดียวจะทำได้อย่างมีประสิทธิภาพภายใต้ข้อสมมติฐานเพิ่มเติมดังต่อไปนี้

  • สมมติฐานที่ 1: เส้นอัตราผลตอบแทนมีลักษณะแบนราบ (flat yield curve)
  • สมมติฐานที่ 2: เส้นอัตราผลตอบแทนมีการเปลี่ยนแปลงแบบขนาน (parallel shift) เท่านั้น
  • สมมติฐานที่ 3: ถ้าอัตราดอกเบี้ยมีการเปลี่ยนแปลง จะต้องมีการเปลี่ยนแปลงเพียงครั้งเดียวเท่านั้น

🎯 จำสั้น

  • 3 สมมติฐาน: Flat curve / Parallel shift / เปลี่ยนครั้งเดียว

🔥 เก็งข้อสอบ

ท่อง: "แบน · ขนาน · ครั้งเดียว" — ข้อสอบมักให้ตัวเลือกที่ 4 ปลอมๆ เช่น "ไม่มีต้นทุนธุรกรรม" หรือ "ผู้ออกไม่ผิดนัด"

Multiple Liabilities Immunization ออกบ่อย

ที่มา: หน้า 34

กลยุทธ์การลงทุนแบบอิมมูไนเซชั่นสำหรับภาระผูกพันที่ต้องจ่ายหลายงวด (multiple liabilities immunization strategy)

หลักการที่สำคัญ คือ ดูเรชั่นของกลุ่มสินทรัพย์เท่ากับดูเรชั่นของกลุ่มภาระผูกพัน โดยมูลค่าปัจจุบันของสินทรัพย์ควรจะมากกว่ามูลค่าปัจจุบันของภาระผูกพันเพื่อลดความเสี่ยงที่กระแสเงินสดรับจะน้อยกว่าภาระกระแสเงินสดจ่ายในอนาคต และการกระจายตัวของดูเรชั่นของกลุ่มสินทรัพย์กว้างกว่าการกระจายตัวของดูเรชั่นของกลุ่มภาระผูกพัน

🎯 จำสั้น

  • Multiple Liabilities: Duration สินทรัพย์ = Duration หนี้สิน
  • PV สินทรัพย์ > PV หนี้สิน + การกระจาย Duration กว้างกว่า

🔥 เก็งข้อสอบ — 3 เงื่อนไขต้องครบ

  1. Dasset = Dliability
  2. PVasset > PVliability
  3. การกระจาย Dasset กว้างกว่า Dliability

1.4 Unified Approach: หลักการ ออกบ่อย

ที่มา: หน้า 43

1.4.1 หลักการของกลยุทธ์

เป็นกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารหนี้โดยแยกการลงทุนตามความเสี่ยงและความชำนาญของผู้ลงทุน โดยผลตอบแทนของกลุ่มหลักทรัพย์ตราสารหนี้จะเปรียบเทียบกับดัชนีอ้างอิง (benchmark) ซึ่งนักลงทุนอาจสร้างกลุ่มหลักทรัพย์ตราสารหนี้ให้ได้ผลตอบแทนเหมือนดัชนีอ้างอิง หรือมีโอกาสชนะดัชนีอ้างอิง ทั้งนี้กลยุทธ์ในกลุ่มนี้จะขึ้นอยู่กับประสบการณ์และระดับการยอมรับความเสี่ยงของนักลงทุน

  1. การสร้างกลุ่มหลักทรัพย์ตราสารหนี้แบบเบต้า (beta portfolio)
  2. การสร้างกลุ่มหลักทรัพย์ตราสารหนี้แบบอัลฟ่า (alpha portfolio)

🎯 จำสั้น

  • Unified = แยกตาม ความเสี่ยง + ความชำนาญ
  • 2 แบบ: Beta (เท่าดัชนี) / Alpha (ชนะดัชนี)

Beta Portfolio: Fully/Partially Replicate ออกแน่นอน

ที่มา: หน้า 44

คือการสร้างผลตอบแทนของกลุ่มหลักทรัพย์ตราสารหนี้ให้เท่ากับผลตอบแทนตลาด หรือผลตอบแทนอ้างอิง ซึ่งเป็นความพยายามในการสร้างผลตอบแทนที่ชดเชยความเสี่ยงที่เป็นระบบ (systematic risk) เท่านั้น มี 2 วิธี

  1. การซื้อตราสารหนี้ทั้งหมดในดัชนีอ้างอิงตามสัดส่วน (fully replicate)
  2. การซื้อตราสารหนี้ที่เป็นตัวแทนของดัชนีอ้างอิงเพียงบางส่วน (partially replicate)

Alpha Portfolio: ชนะ/แพ้ Benchmark และ Alpha Return คำนวณออกบ่อย

ที่มา: หน้า 46

คือการสร้างผลตอบแทนของกลุ่มหลักทรัพย์ตราสารหนี้ให้มากกว่าผลตอบแทนตลาด หรือผลตอบแทนอ้างอิง ซึ่งเป็นความพยายามในการสร้างผลตอบแทนที่ชดเชยความเสี่ยงที่เป็นระบบ (systematic risk) และความเสี่ยงเฉพาะตัว (idiosyncratic risk)

ตัวอย่างเช่น กลุ่มหลักทรัพย์ตราสารหนี้ของนักลงทุนในปีที่ผ่านมาสร้างผลตอบแทนได้ 4% ในขณะที่ผลตอบแทนอ้างอิงให้ผลตอบแทน 3% แสดงว่ากลุ่มหลักทรัพย์ตราสารหนี้ของนักลงทุนมีผลตอบแทนอัลฟ่า (alpha return) เท่ากับ 1% แต่ในทางกลับกัน หากกลุ่มหลักทรัพย์ตราสารหนี้ในปีที่ผ่านมาสร้างผลตอบแทนได้เพียง 2% แสดงว่ากลุ่มหลักทรัพย์ตราสารหนี้ของนักลงทุนมีผลตอบแทนอัลฟ่า (alpha return) เท่ากับ −1%

🎯 จำสั้น

  • Alpha = ผลตอบแทน − ผลตอบแทนดัชนี
  • 4% vs 3% → alpha = +1% / 2% vs 3% → alpha = −1%

🔥 เก็งข้อสอบ

อย่าสับสน: Alpha ในหน้านี้ = ผลต่างตรงๆ (Rp − Rbenchmark) ต่างจาก Jensen's Alpha (หน้า 113) ที่ต้องปรับด้วย Beta ก่อน — ข้อสอบชอบเอามาปนกัน

  2. ความเสี่ยงที่นักลงทุนเข้าใจและยอมรับได้

📝 คำถามทบทวนท้ายบทที่ 1

1. ถ้าคาดว่าอัตราดอกเบี้ยจะเพิ่มขึ้น ควรเพิ่มหรือลด Duration เพราะเหตุใด?
เฉลย ลด Duration — เพราะเมื่อดอกเบี้ยขึ้น ราคาตราสารหนี้จะลง และพันธบัตรที่ Duration สูงจะ ขาดทุนมากกว่า พันธบัตรที่ Duration ต่ำ → ลด Duration เพื่อลดความเสียหาย
2. Parallel Shift ต่างจาก Steepening/Flattening อย่างไร?
เฉลย Parallel Shift = ดอกเบี้ยทุกช่วงอายุขยับขึ้น/ลง เท่ากัน
Steepening = ช่วงยาวขึ้นมากกว่าช่วงสั้น (เส้นชันขึ้น)
Flattening = ช่วงสั้นขึ้นมากกว่าช่วงยาว (เส้นแบนลง)
3. Bullet, Barbell และ Ladder ต่างกันที่การกระจายอายุของตราสารอย่างไร?
เฉลย Bullet = กระจุกที่อายุเดียว / Barbell = กระจายที่อายุสั้น+ยาว (สองหัว) / Ladder = กระจายเท่ากันทุกช่วงอายุ
4. Immunization กับ Cash Flow Matching เน้นจับคู่สิ่งใด?
เฉลย Immunization = จับคู่ Duration ของสินทรัพย์ให้เท่ากับระยะเวลาภาระผูกพัน / Cash Flow Matching = จับคู่ กระแสเงินสดรับ ให้ตรงกับ กระแสเงินสดจ่าย ในแต่ละงวด
5. Beta Portfolio กับ Alpha Portfolio ต่างกันอย่างไรเมื่อเทียบกับ Benchmark?
เฉลย Beta = ทำผลตอบแทนให้ เท่าดัชนี (ชดเชย systematic risk เท่านั้น) / Alpha = พยายาม ชนะดัชนี (รับทั้ง systematic + idiosyncratic risk)

Passive vs Active

Passive ตั้งอยู่บนแนวคิดว่าตลาดมีประสิทธิภาพอย่างสมบูรณ์ จึงไม่จำเป็นต้องค้นหาหุ้นที่ mispriced หรือจับจังหวะตลาด; พอร์ตควรเลียนแบบดัชนีมาตรฐาน

Active เชื่อว่าราคาตลาดอาจไม่สะท้อนมูลค่าที่ควรเป็น จึงพยายามคัดเลือกหลักทรัพย์หรือจับจังหวะเพื่อมีโอกาสชนะตลาด

⚠️ อย่าสับสน

Passive = ตามดัชนี; Active = พยายามชนะดัชนี ไม่ได้หมายความว่า Active จะชนะเสมอ

กลยุทธ์ Passive 4 แบบ

  1. Full Replication — ซื้อหลักทรัพย์ทุกตัวตามน้ำหนักของดัชนี แล้วติดตาม/ปรับพอร์ต
  2. Stratified Sampling — เลือกบางส่วนที่เป็นตัวแทนของดัชนี เช่น SET50 ใช้แทน SET Index
  3. Optimization — ใช้แบบจำลองคณิตศาสตร์ เช่น quadratic optimization เพื่อให้ผลตอบแทนใกล้ดัชนี โดยมักใช้หลักทรัพย์น้อยลง
  4. Blended — ผสม Value Stock Index กับ Growth Stock Index เช่น 50:50 หรือ 60:40 ตามเป้าหมาย

Tracking Error

เป็นค่าความแตกต่างระหว่างผลตอบแทนของพอร์ตเชิงรับกับผลตอบแทนมาตรฐานที่ต้องการเลียนแบบ และในทางปฏิบัติ Beta ของพอร์ตเชิงรับอาจไม่เท่ากับ 1.0

📝 จุดที่ชอบออกสอบ

ค่าเฉลี่ย 5 ปี: SET = -2.29%, SET50 = -2.58%, ผลต่าง = 0.29%

Active: Fundamental vs Quantitative

Fundamental Active ใช้ดุลยพินิจ วิเคราะห์ข้อมูลเชิงปริมาณ/คุณภาพ อุตสาหกรรม งบการเงิน กระแสเงินสด กำไร และมูลค่า

Quantitative Active ใช้แบบจำลองเชิงปริมาณ ข้อมูลอดีต ฐานข้อมูล back-testing, out-of-sample และ variance-covariance matrix

Active styles ที่ต้องจำ

  • Bottom-Up: เริ่มจากบริษัท/หุ้นรายตัว; Value-based และ Growth-based
  • Top-Down: เริ่มจากภาพใหญ่ เช่น Asset Allocation, Sector Rotation, Thematic
  • Factor-Based: ใช้ Size, Value, Price Momentum, Growth
  • Activist: เข้าถือหุ้นเพื่อกดดัน/ผลักดันการเปลี่ยนแปลง
  • Statistical Arbitrage / Market Microstructure: ใช้สถิติ เทคนิค เศรษฐมิติ หรือ Machine Learning หาความผิดปกติของราคา
  • Event-Driven: ลงทุนตามข่าว/เหตุการณ์ เช่น M&A, restructuring, capital increase, buyback หรือการขายหุ้นบริษัทย่อย/บริษัทร่วม

ข้อควรระวัง Quantitative

ระวัง survivorship bias, look-ahead bias และ overfitting จาก noise

🔥 เก็งบทที่ 2 — 5 ประโยคที่ต้องท่องได้

  1. Tobin's Q < 1 = ราคาตลาดต่ำกว่ามูลค่าทดแทนสินทรัพย์ → undervalued
  2. PEG = P/E ÷ Growth → P/E สูงแต่ PEG ต่ำ = ยังสมเหตุสมผล
  3. Quant 3 bias: Survivorship · Look-ahead · Overfitting
  4. Full Replication: Mismatch/TE ต่ำ แต่ Transaction Cost สูง
  5. Active สำเร็จขึ้นกับ Stock Selection + Market Timing

2.2.1 หลักการของกลยุทธ์

เชื่อว่าตลาดมีประสิทธิภาพอย่างสมบูรณ์ ข้อมูลที่มีผลต่อการเปลี่ยนแปลงของราคาหลักทรัพย์ได้สะท้อนอยู่ในราคาตลาดของหลักทรัพย์นั้นๆ เรียบร้อยแล้ว ดังนั้น การวิเคราะห์หลักทรัพย์เพื่อแสวงหาหุ้น (stock selection) ที่มีราคาไม่สอดคล้องกับราคาที่ควรจะเป็น (intrinsic value) จึงเป็นกระบวนการที่ไม่จำเป็น รวมทั้งการจับจังหวะการลงทุน (market timing) เป็นสิ่งที่เป็นไปได้ยากหรือเป็นไปไม่ได้ ดังนั้น หากตลาดมีประสิทธิภาพสมบูรณ์อย่างแท้จริงแล้ว ผู้ลงทุนควรลงทุนในกลุ่มหลักทรัพย์ที่กระจายความเสี่ยงในลักษณะเดียวกับดัชนีมาตรฐานเปรียบเทียบ ซึ่งอาจอยู่ในรูปแบบของ Index Fund

🎯 จำสั้น

  • Beta ในทางทฤษฎี = 1.0 แต่ในทางปฏิบัติไม่เคยเท่าเป๊ะ
  • Tracking Error = ตัววัดผลต่าง

Full Replication Strategy คือการสร้าง Index fund ชนิดเต็มรูปแบบ เป็นลักษณะที่สร้างขึ้นได้ง่ายและตรงไปตรงมาที่สุด หากนักลงทุนเลือกดัชนีมาตรฐานเปรียบเทียบเป็นที่เรียบร้อยแล้ว ขั้นตอนเพื่อสร้าง Index fund ชนิดเต็มรูปแบบประกอบด้วย 3 ขั้นตอนดังต่อไปนี้

  1. ขั้นที่ 1 นักลงทุนจะต้องค้นหาข้อมูลเกี่ยวกับหลักทรัพย์ทุกตัวที่เป็นส่วนประกอบของดัชนีมาตรฐานเปรียบเทียบ
  2. ขั้นที่ 2 นักลงทุนจะเข้าลงทุนในหลักทรัพย์ทุกหลักทรัพย์ และลงทุนตามน้ำหนักการลงทุน
  3. ขั้นที่ 3 เมื่อนักลงทุนสร้างพอร์ตการลงทุนตาม SET Index เป็นที่เรียบร้อยแล้ว นักลงทุนจะต้องติดตามและปรับพอร์ตการลงทุนดังกล่าวเป็นระยะๆ

🎯 จำสั้น

  • 3 ขั้น: ค้นหาหลักทรัพย์ → ลงทุนตามน้ำหนัก → ติดตาม/ปรับ

🔥 เก็งข้อสอบ

ที่มา: หน้า 58

นักลงทุนสามารถสร้างพอร์ตการลงทุนที่มีลักษณะคล้ายคลึงกับดัชนีมาตรฐานเปรียบเทียบที่เลือกขึ้นมา โดยอาจเลือกลงทุนในหุ้นที่มีมูลค่าตลาด (market capitalization) ขนาดใหญ่จำนวนหนึ่ง ตัวอย่างเช่น การลงทุนในดัชนี SET50 เพื่อใช้เป็นตัวแทนของ SET Index เป็นตัวอย่างหนึ่งของกลยุทธ์รูปแบบ Stratified Sampling Strategy เพื่อให้ผลตอบแทนของกลุ่มหลักทรัพย์ใกล้เคียงกับ SET Index

หากพิจารณาถึงค่าสัมประสิทธิ์สหสัมพันธ์ (correlation coefficient) ระหว่างดัชนี SET Index และดัชนี SET50 Index อยู่ในระดับที่สูงมากถึง 0.98 และหากพิจารณาถึงค่าสัมประสิทธิ์สหสัมพันธ์ระหว่างผลตอบแทนของ SET Index และผลตอบแทนของ SET50 Index ในช่วงเวลาเดียวกัน จะพบว่าดัชนีทั้งสองมีค่าความสัมพันธ์สูงถึงร้อยละ 0.99

  • Stratified Sampling = ใช้ SET50 แทน SET
  • Correlation 0.98–0.99 → ใกล้เคียงมาก

Optimization Strategy ออกบ่อย

ที่มา: หน้า 60

การสร้าง Index Fund โดยใช้แบบจำลองทางคณิตศาสตร์ เช่น แบบจำลอง quadratic optimization model เป็นวิธีการสร้างแบบจำลองเพื่อใช้ในการคัดเลือกหลักทรัพย์ ที่จะสามารถสร้างผลตอบแทนให้สอดคล้องและใกล้เคียงกับผลตอบแทนของดัชนีมาตรฐานเปรียบเทียบให้ได้มากที่สุด พอร์ตการลงทุนที่ได้จากการใช้แบบจำลองดังกล่าวนี้ มักจะประกอบกันขึ้นจากหลักทรัพย์ในจำนวนที่น้อยกว่า การสร้าง Index Fund ตามรูปแบบ Full Replication Strategy หรือตามรูปแบบ Stratified Sampling Strategy

🎯 จำสั้น

  • Optimization = ใช้ โมเดลคณิตศาสตร์ (quadratic optimization)
  • ใช้หลักทรัพย์ น้อยกว่า Full Replication แต่ผลตอบแทนใกล้เคียง

🔥 เก็งข้อสอบ

คีย์เวิร์ด: quadratic optimization + ใช้หลักทรัพย์น้อยที่สุดใน 3 วิธี

เรียงลำดับจำนวนหลักทรัพย์: Full Replication > Stratified Sampling > Optimization

Blended Strategy ออกได้

ที่มา: หน้า 61

Blended Strategy คือ กลยุทธ์การสร้างพอร์ตการลงทุนที่ผสมผสานระหว่างหุ้นเน้นคุณค่า (value stock) กับหุ้นเน้นเติบโต (growth stock) โดยนักลงทุนอาจสร้างพอร์ตการลงทุนโดยอิงกับดัชนีมาตรฐานเปรียบเทียบ ได้แก่ Value Stock Index หรือ Growth Stock Index นักลงทุนที่ใช้กลยุทธ์นี้คาดหวังผลตอบแทนจากส่วนต่างกำไรจากหุ้นเน้นเติบโต ในขณะเดียวกันก็คาดหวังผลตอบแทนในรูปเงินปันผลจากหุ้นเน้นคุณค่า โดยอาจกำหนดสัดส่วนการลงทุนระหว่าง Value Stock Index กับ Growth Stock Index เป็นในอัตราส่วน 50:50 หรือ 60:40 หรือแล้วแต่เป้าหมายของนักลงทุน

🎯 จำสั้น

  • Blended = ผสม Value + Growth
  • สัดส่วน 50:50 หรือ 60:40 แล้วแต่เป้าหมาย

🔥 เก็งข้อสอบ

จับคู่ผลตอบแทน: Growth → capital gain | Value → เงินปันผล

2.3 Active: หลักการ ออกแน่นอน

ที่มา: หน้า 63

2.3.1 หลักการของกลยุทธ์

เชื่อว่าราคาตลาดของหลักทรัพย์มีราคาไม่สอดคล้องกับระดับราคาที่ควรจะเป็น ดังนั้น นักลงทุนจึงต้องศึกษาทฤษฎีเพื่อค้นหาหลักทรัพย์ที่มีราคาตลาดต่ำกว่ามูลค่าที่ควรจะเป็น หรือใช้วิธีการจับจังหวะการลงทุน ซึ่งจะทำให้นักลงทุนมีโอกาสสร้างผลตอบแทนได้มากกว่าตลาด หรือดัชนีมาตรฐานเปรียบเทียบ

  1. คัดเลือกหลักทรัพย์ที่คาดว่าจะให้ผลตอบแทนสูงกว่าอัตราผลตอบแทนของตลาด
  2. การใช้การจับจังหวะการลงทุน

🎯 จำสั้น

  • Active = เลือกหุ้น + จับจังหวะตลาด

🔥 เก็งข้อสอบ — ตรงกับแนวข้อสอบ 2

ความสำเร็จของ Active Equity Management ขึ้นอยู่กับอะไร

เฉลย: Stock Selection และ Market Timing

Fundamental Active vs Quantitative Active ออกบ่อย

ที่มา: หน้า 64

แนวคิดหลักของกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารทุนเชิงรุกแบ่งเป็น 2 รูปแบบ

  1. การตัดสินใจลงทุนภายใต้กลยุทธ์การลงทุนแบบ Fundamental Active นักลงทุนจะเน้นการใช้ดุลยพินิจ หรือวิจารณญาณ (discretionary) ของนักลงทุนเป็นหลัก นักลงทุนเชื่อว่าราคาหลักทรัพย์ของบริษัทในปัจจุบันไม่สะท้อนความเสี่ยงของบริษัท ดังนั้นราคาหลักทรัพย์ที่ซื้อขายอยู่ในปัจจุบันจึงเป็นราคาที่สูงกว่าที่ควรจะเป็น (overpriced) หรือเป็นราคาที่ต่ำกว่าที่ควรจะเป็น (underpriced)
  2. การตัดสินใจลงทุนของนักลงทุนโดยใช้กลยุทธ์การลงทุนแบบ Quantitative Active จะเน้นการใช้แบบจำลองเชิงปริมาณ (quantitative model) เป็นหลัก กลยุทธ์การลงทุนแบบนี้นักลงทุนจะเน้นการวิเคราะห์โดยใช้ข้อมูลในอดีตของบริษัท เพื่อนำมาสร้างแบบจำลอง สร้างเงื่อนไขในการลงทุน และทดสอบข้อมูลย้อนหลัง (back-testing)

🎯 จำสั้น

  • Fundamental = ใช้ดุลยพินิจคน
  • Quantitative = ใช้โมเดล + back-testing

🔥 เก็งข้อสอบ

คีย์เวิร์ดตัดตัวเลือก: discretionary = Fundamental | back-testing = Quantitative

ขั้นตอน Fundamental Active 7 ขั้น จำลำดับ

ที่มา: หน้า 65

2.3.2 แนวทางการสร้างกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารทุนเชิงรุก – Fundamental Active

  1. ขั้นที่ 1 กำหนดขอบเขตหลักทรัพย์ที่นักลงทุนสามารถลงทุนได้ (investment universe)
  2. ขั้นที่ 2 คัดกรองหลักทรัพย์ที่นักลงทุนคาดว่าจะลงทุนได้ในเบื้องต้น โดยพิจารณาจากข้อมูลทั้งเชิงปริมาณ และข้อมูลเชิงคุณภาพ
  3. ขั้นที่ 3 ทำความเข้าใจอุตสาหกรรมโดยวิเคราะห์การแข่งขันภายในอุตสาหกรรม และทำความเข้าใจธุรกิจจากการวิเคราะห์รายงานทางการเงิน
  4. ขั้นที่ 4 พยากรณ์ผลการดำเนินงานของบริษัทในอนาคตจากกระแสเงินสด และความสามารถในการทำกำไรของกิจการ
  5. ขั้นที่ 5 ประเมินมูลค่าของกิจการ หรือราคาหุ้น
  6. ขั้นที่ 6 สร้างพอร์ตการลงทุนโดยเลือกหุ้นเข้าพอร์ตจากการประเมินมูลค่า และระดับความเสี่ยงที่ยอมรับได้
  7. ขั้นที่ 7 มีวินัยในการซื้อหรือขายเพื่อปรับสมดุลพอร์ตการลงทุน (rebalance portfolio)

🎯 จำสั้น

  • 7 ขั้น: กำหนดขอบเขต → กรอง → เข้าใจอุตสาหกรรม → พยากรณ์ → ประเมินมูลค่า → สร้างพอร์ต → rebalance

🔥 เก็งข้อสอบ

ท่องคำแรกของแต่ละขั้น: ขอบเขต · กรอง · อุตสาหกรรม · พยากรณ์ · มูลค่า · พอร์ต · rebalance (7 ขั้น)

ขั้นตอน Quantitative Active 5 ขั้น จำลำดับ

ที่มา: หน้า 66

2.3.2 แนวทางการสร้างกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารทุนเชิงรุก – Quantitative Active

  1. ขั้นที่ 1 ระบุโอกาสในการลงทุนที่ผ่านกระบวนการทำวิจัย และวิเคราะห์อย่างเป็นระบบ (investment thesis)
  2. ขั้นที่ 2 ให้ความสำคัญกับการสร้างฐานข้อมูล การจัดการข้อมูลจากแหล่งข้อมูลที่หลากหลาย การเตรียมความพร้อมของข้อมูลให้สามารถใช้งานได้อยู่เสมอ
  3. ขั้นที่ 3 ทดสอบแบบจำลองย้อนหลัง (back-testing)
  4. ขั้นที่ 4 ประเมินแบบจำลองด้วยวิธี out-of-sample back-test
  5. ขั้นที่ 5 พิจารณา variance-covariance matrix ของพอร์ตลงทุนเพิ่มเติม

🎯 จำสั้น

  • 5 ขั้น: thesis → ข้อมูล → back-test → out-of-sample → variance-covariance

🔥 เก็งข้อสอบ

ลำดับสำคัญ: back-test ต้องมาก่อน out-of-sample เสมอ — ข้อสอบชอบสลับ 2 ขั้นนี้

    • Illusion of Control
    • Availability bias
  • ความเอนเอียงทางอารมณ์ (emotional biases):
    • Loss aversion
    • Overconfidence bias
    • Regret aversion bias

2) กับดักมูลค่า และกับดักอัตราการเติบโต

🎯 จำสั้น

  • 2 กลุ่มอคติ: Cognitive (Confirmation / Illusion / Availability) + Emotional (Loss / Overconfidence / Regret)
  • ระวัง 2 กับดัก: มูลค่า + การเติบโต

🔥 เก็งข้อสอบ — ให้สถานการณ์ ระบุชื่ออคติ

2.3.3 ข้อพึงระวังการสร้างกลยุทธ์การบริหารกลุ่มหลักทรัพย์ตราสารทุน – Quantitative Active

  1. แบบจำลองส่วนใหญ่ที่นักลงทุนใช้สำหรับการบริหารกลุ่มหลักทรัพย์ตราสารทุนแบบ Quantitative Active มักเป็นการนำข้อมูลจากบริษัทที่อยู่รอด หรือกำลังดำเนินธุรกิจอยู่มาสร้างแบบจำลอง (survivorship bias)
  2. อคติที่เกิดจากการใช้ข้อมูลที่ยังไม่มีอยู่จริงในช่วงเวลาที่นักลงทุนตัดสินใจลงทุน (look-ahead bias) โดยส่วนใหญ่มักจะเป็นข้อมูลรายงานทางการเงิน
  3. แบบจำลองอาจตอบสนองต่อข้อมูลที่มีลักษณะเป็น noise จนทำให้แบบจำลองที่ใช้ในการพยากรณ์ผลตอบแทนของหลักทรัพย์ผิดเพี้ยนไป จนแบบจำลองมีลักษณะเป็น overfitting

2.3.4.1 กลยุทธ์แบบ Bottom-Up ประกอบด้วย

การลงทุนแบบเน้นคุณค่าโดยวิธีหามูลค่าเชิงเปรียบเทียบ (relative value) พิจารณาจาก

  1. อัตราส่วนราคาตลาด/กำไรต่อหุ้น (Price/Earnings Ratio)
  2. อัตราส่วนราคาตลาดต่อราคาทางบัญชีต่อหุ้น (Price / Book Value Per Share Ratio)
  3. อัตราส่วนราคาตลาดของสินทรัพย์ของกิจการต่อราคาเปลี่ยนแทน หรือ Tobin's Q Ratio

🎯 จำสั้น

  • Value ใช้ 3 ratio: P/E / P/BVPS / Tobin's Q

🔥 เก็งข้อสอบ — ตรงกับแนวข้อสอบ 2 ทุกข้อ

Ratioสัญญาณ undervalued
P/Eต่ำกว่าค่าเฉลี่ยอุตสาหกรรม
P/BVต่ำกว่าคู่แข่ง

2.3.4.1 กลยุทธ์แบบ Bottom-Up - แนวทางการลงทุนแบบเน้นคุณค่า (value-based approach)

  • การลงทุนแบบเน้นคุณค่าโดยสวนทางกับตลาด (contrarian value investor)
  • การลงทุนแบบเน้นคุณค่าในกิจการที่จ่ายเงินปันผลสูง (income investing)
  • การลงทุนแบบเน้นคุณค่าในกิจการที่กำลังจะเข้าสู่กระบวนการปรับปรุงโครงสร้าง (restructuring and distressed investing)
  • การลงทุนในหุ้นคุณค่าโดยมีส่วนร่วมในการบริหาร

🎯 จำสั้น

  • Value investing 4 แบบ: Contrarian / Income / Restructuring / Active

🔥 เก็งข้อสอบ

อย่าสับสน: "ลงทุนหุ้นคุณค่าโดยมีส่วนร่วมในการบริหาร" (หน้า 72) ≠ Activist Strategy (หน้า 77) ที่เข้าถือหุ้นเพื่อกดดันทีมบริหารโดยเฉพาะ

Growth-based: กำไรเติบโต, P/E สูง และ PEG ออกแน่นอน

ที่มา: หน้า 73

2.3.4.1 กลยุทธ์แบบ Bottom-Up - แนวทางการลงทุนแบบเน้นการเติบโต (growth-based approaches)

  • คัดเลือกหุ้นที่มีการคาดการณ์การเติบโตของกำไรสุทธิอยู่ในระดับสูง
  • คัดเลือกหุ้นที่มี P/E สูง
  • คัดเลือกหุ้นที่มี P/E ในระดับสูงที่สอดคล้องกับอัตราการเติบโตโดยใช้ PEG Ratio

🎯 จำสั้น

  • Growth: กำไรโตสูง + P/E สูง + PEG สอดคล้อง
  • PEG = Price/Earnings to Growth Ratio = อัตราส่วนราคาต่อกำไรเทียบกับอัตราการเติบโต

🔥 เก็งข้อสอบ

PEG = P/E ÷ อัตราการเติบโตของกำไร (%)

ชื่อเต็ม: Price/Earnings to Growth Ratio — ใช้ดูว่า P/E ที่สูงนั้น "แพงเกินไป" หรือ "สมเหตุสมผลกับการเติบโต"

หุ้น A: P/E 30, Growth 30% | หุ้น B: P/E 20, Growth 10% — ตัวไหนน่าสนใจกว่าตามแนว Growth

A: PEG = 30/30 = 1.0 | B: PEG = 20/10 = 2.0 → หุ้น A น่าสนใจกว่า แม้ P/E สูงกว่า เพราะการเติบโตรองรับ

กับดัก: ข้อสอบชอบหลอกว่า "P/E สูง = แพง = ไม่ควรซื้อ" → ผิดในบริบท Growth ต้องดู PEG ประกอบ

3. ทำไม SET50 จึงใช้เป็นตัวแทน SET Index ในตัวอย่าง Stratified Sampling?

4. Fundamental Active ต่างจาก Quantitative Active ที่วิธีตัดสินใจอย่างไร?
เฉลย Fundamental = ใช้ ดุลยพินิจ (discretionary) วิเคราะห์งบการเงิน อุตสาหกรรม / Quantitative = ใช้ โมเดลเชิงปริมาณ + ข้อมูลอดีต + back-testing
5. Bottom-Up, Top-Down และ Factor-Based เริ่มจากมุมมองใด?
เฉลย Bottom-Up = เริ่มจาก บริษัท/หุ้นรายตัว / Top-Down = เริ่มจาก ภาพใหญ่ (เศรษฐกิจ, sector) / Factor-Based = เริ่มจาก ปัจจัย (Size, Value, Momentum, Growth)

VaR

Value at Risk (VaR) คือการวัดมูลค่าความเสียหายที่อาจเกิดขึ้นโดยอาศัยความน่าจะเป็น

Z = (μ* − μ) / σ
  • Z = ค่ามาตรฐาน
  • μ = ผลตอบแทนที่คาดหวัง
  • μ* = ผลขาดทุนสูงสุดที่ยอมรับได้ตามนิยามในสไลด์
  • σ = ส่วนเบี่ยงเบนมาตรฐานของผลตอบแทน

ตัวอย่างในเอกสาร: 1-day VaR = 1.5 ล้านบาท ที่ confidence 95% หมายถึงโอกาส 95% ที่ขาดทุนน้อยกว่า 1.5 ล้านบาทภายใน 1 วัน และโอกาส 5% ที่ขาดทุนเกิน 1.5 ล้านบาท

3 วิธี VaR

  • Variance-Covariance: Normal Distribution + Z-variable
  • Historical: ผลตอบแทนอดีต + Histogram + percentile เช่น 5% หรือ 1%
  • Monte Carlo Simulation: สร้างผลตอบแทนจำลองตามสมมติฐาน แล้วหา VaR

3.3 การสำรวจและระบุความเสี่ยง โครงสร้าง

ที่มา: หน้า 87

การสำรวจและระบุความเสี่ยง แบ่งออกเป็น ความเสี่ยงทางการเงิน และ ความเสี่ยงที่ไม่ใช่ทางการเงิน

🎯 จำสั้น

  • 2 ประเภทความเสี่ยง: การเงิน + ไม่ใช่การเงิน

🔥 เก็งข้อสอบ

จำเลข: การเงิน 5 ตัว (หน้า 88) + ไม่ใช่การเงิน 3 ตัว (หน้า 89) + ESG 3 ตัว (หน้า 90)

ความเสี่ยงทางการเงิน: 5 ประเภท ออกแน่นอน

ที่มา: หน้า 88
  • ความเสี่ยงด้านตลาด (market risk) เป็นความเสี่ยงที่เกี่ยวข้องกับการเปลี่ยนแปลงของอัตราดอกเบี้ย อัตราแลกเปลี่ยน ราคาสินทรัพย์ หุ้นสามัญ หรือสินค้าโภคภัณฑ์ ที่อาจส่งผลกระทบต่อผลตอบแทนของกลุ่มหลักทรัพย์
  • ความเสี่ยงด้านเครดิต (credit risk) เป็นความเสี่ยงที่คู่สัญญาไม่ปฏิบัติตามสัญญา เช่น ผู้กู้ยืมไม่จ่ายชำระคืนเงินต้น หรือดอกเบี้ย หรือจ่ายชำระได้ไม่เต็มจำนวน ในบางครั้งอาจเรียกความเสี่ยงนี้ว่าความเสี่ยงจากการผิดนัดชำระหนี้ (default risk)
  • ความเสี่ยงด้านสภาพคล่อง (liquidity risk) เป็นความเสี่ยงจากตราสารทางการเงินที่ซื้อขายในตลาดไม่สามารถแปลงเป็นเงินสดได้ทันที
  • ความเสี่ยงด้านการชำระราคาและการส่งมอบ (settlement or counterparty risk) เป็นความเสี่ยงที่เกิดจากการที่คู่สัญญาได้ส่งมอบสินทรัพย์ หรือหลักทรัพย์แล้ว แต่ยังไม่ได้รับชำระราคาจากคู่สัญญาอีกฝ่ายหนึ่ง
  • ความเสี่ยงจากการใช้แบบจำลองที่ผิดพลาด (model risk) เป็นความเสี่ยงที่เกิดจากการใช้แบบจำลองในการประเมินมูลค่าหลักทรัพย์ที่ผิดพลาด

🎯 จำสั้น

  • 5 ความเสี่ยงการเงิน: Market / Credit / Liquidity / Settlement-Counterparty / Model

  • ความเสี่ยงด้านการดำเนินงาน (operational risk) เป็นความเสี่ยงที่อาจก่อให้เกิดความเสียหายจากความผิดพลาดของระบบ กระบวนการการทำงานในบริษัท หรือความผิดพลาดของผู้ปฏิบัติงาน

ESG: Environment, Social, Governance ออกบ่อย

ที่มา: หน้า 90

ความเสี่ยงด้าน ESG เป็นอีกความเสี่ยงที่นักลงทุนทั่วโลกในปัจจุบันให้ความสำคัญ เนื่องจากเป็นความเสี่ยงที่ส่งผลต่อมูลค่าตลาดของบริษัท อันเนื่องมาจากประเด็นด้านสิ่งแวดล้อม (environment) สังคม (social) และธรรมาภิบาล (governance)

  • ประเด็นความเสี่ยงด้านสิ่งแวดล้อม (E) เกี่ยวข้องกับการตัดสินใจนำเสนอผลิตภัณฑ์ หรือบริการที่ส่งผลกระทบต่อสิ่งแวดล้อมทางด้านลบ เช่น การใช้พลาสติกที่ไม่สามารถย่อยสลายได้ในกระบวนการผลิต การปล่อยน้ำเสีย หรือการสร้างมลพิษทางอากาศระหว่างกระบวนการผลิต
  • ประเด็นความเสี่ยงด้านสังคม (S) เกี่ยวข้องกับการดำเนินนโยบายด้านการบริหารทรัพยากรบุคคล สภาพแวดล้อมในที่ทำงาน หรือความเสี่ยงที่อาจก่อให้เกิดอุบัติเหตุในที่ทำงาน เป็นต้น
  • ประเด็นความเสี่ยงด้านธรรมาภิบาล (G) เกี่ยวข้องกับการวางโครงสร้างการกำกับดูแล การเปิดเผยข้อมูล ความโปร่งใสในการบริหารงาน เป็นต้น

ทั้งสามประเด็นนี้จะเป็นความท้าทายของบริษัทที่กระทบต่อความยั่งยืน และความอยู่รอดในการดำเนินธุรกิจ

🎯 จำสั้น

  • E = สิ่งแวดล้อม | S = สังคม/พนักงาน | G = ธรรมาภิบาล

🔥 เก็งข้อสอบ — ตรงกับแนวข้อสอบ 2

"การวางโครงสร้างกำกับดูแล การเปิดเผยข้อมูล และความโปร่งใส" จัดเป็นความเสี่ยงด้านใด

เฉลย: Governance (G)

กับดัก: "อุบัติเหตุในที่ทำงาน" ดูเหมือน Operational แต่ในบริบท ESG จัดเป็น Social (S)

3.4 VaR: ความหมายและการตีความ ออกแน่นอน

ที่มา: หน้า 91

การคำนวณมูลค่าความเสี่ยง (Value at Risk) หรือ VaR เป็นการวัดมูลค่าความเสียหายที่อาจเกิดขึ้นกับกลุ่มหลักทรัพย์โดยอาศัยหลักความน่าจะเป็น โดยมูลค่าความเสียหายนั้นอาจแสดงในรูปของเปอร์เซ็นต์ หรือจำนวนเงิน ซึ่งการคำนวณมูลค่าความเสียหายที่เกิดขึ้นนั้นมักเป็นความเสียหายที่เกิดขึ้นจากความเสี่ยงด้านตลาด (market risk) เป็นหลัก

ตัวอย่างเช่น มูลค่าความเสี่ยงของกลุ่มหลักทรัพย์ เท่ากับ 1.5 ล้านบาท ใน 1 วัน (1-day VaR) ณ ระดับความเชื่อมั่นร้อยละ 95 มีความหมายว่า “มีโอกาส (ความน่าจะเป็น) ร้อยละ 95 ที่กลุ่มหลักทรัพย์จะขาดทุนน้อยกว่า 1.5 ล้านบาทภายใน 1 วัน” หรืออาจกล่าวได้ว่า “มีค่าความผิดพลาดที่จะไม่เป็นไปตามนั้นร้อยละ 5 ที่กลุ่มหลักทรัพย์จะขาดทุนเกิน 1.5 ล้านบาท ภายใน 1 วัน”

🎯 จำสั้น

  • VaR 1.5 ล้าน/วัน, 95% confidence → โอกาส 95% ขาดทุน ≤ 1.5 ล้าน, โอกาส 5% เกิน

🔥 เก็งข้อสอบ — ข้อตีความออกทุกปี

VaR 1 วัน = 2 ล้านบาท ที่ 99% หมายความว่าอย่างไร

เฉลย: มีโอกาส 99% ที่จะขาดทุนไม่เกิน 2 ล้านบาทใน 1 วัน / มีโอกาส 1% ที่ขาดทุนเกิน 2 ล้าน

กับดักคลาสสิก: ตัวเลือกผิดที่พบบ่อย = "ขาดทุนสูงสุด 2 ล้านแน่นอน" → ผิด! VaR ไม่ได้บอกว่าขาดทุนได้มากสุดเท่าไร บอกแค่ threshold ที่ระดับความเชื่อมั่น
จำ: VaR วัด market risk เป็นหลัก ไม่ใช่ credit risk

VaR: ระดับความผิดพลาด α และ Confidence Level ออกบ่อย

ที่มา: หน้า 92

องค์ประกอบของการคำนวณมูลค่าความเสี่ยง – การกำหนดระดับความผิดพลาดที่ยอมรับได้ (α)

หากผู้จัดการกองทุนกำหนดค่า α = 0.05 หมายความว่า ผู้จัดการกองทุนยอมรับว่ามีโอกาสร้อยละ 5 ที่มูลค่าความเสี่ยงของกลุ่มหลักทรัพย์จะมากไปกว่าที่กำหนดไว้ หรือกล่าวอีกนัยหนึ่ง ผู้จัดการกองทุนมีความเชื่อมั่นถึงร้อยละ 95 ที่ผลขาดทุนของกลุ่มหลักทรัพย์จะไม่มากไปกว่าที่กำหนดไว้

🎯 จำสั้น

  • α = 0.05 → confidence = 95% (α + confidence = 1)

🔥 เก็งข้อสอบ

α + Confidence Level = 1 (100%)

α = 0.01 → confidence 99% → Z = 2.33 | α = 0.05 → confidence 95% → Z = 1.65

VaR: ความถี่ข้อมูลและ 3 วิธีคำนวณ ออกบ่อย

ที่มา: หน้า 93

องค์ประกอบของการคำนวณมูลค่าความเสี่ยง

  • การกำหนดช่วงความถี่ของชุดข้อมูล ช่วงความถี่ของชุดข้อมูลส่งผลต่อการคำนวณมูลค่าความเสี่ยงที่แตกต่างกัน โดยช่วงความถี่ของชุดข้อมูล คือ การใช้ผลตอบแทนแบบรายวัน รายสัปดาห์ รายเดือน รายไตรมาส หรือรายปี
  • การเลือกวิธีคำนวณมูลค่าความเสี่ยง ได้แก่ วิธี Variance-Covariance, วิธี Historical, วิธี Monte Carlo Simulation

  • 3 วิธี VaR: Variance-Covariance / Historical / Monte Carlo

Variance-Covariance: Normal Distribution และ Z-variable ออกบ่อย

ที่มา: หน้า 94

วิธี Variance – Covariance มีสมมติฐานที่สำคัญคือ “ผลตอบแทนของหลักทรัพย์ หรือกลุ่มหลักทรัพย์ต้องมีลักษณะการแจกแจงแบบปกติ (normal distribution)” ซึ่งการคำนวณหาค่า VaR ณ ช่วงความเชื่อมั่นหนึ่งๆ จะผ่านการคำนวณหาตัวแปรมาตรฐาน (standardized variable) ของผลตอบแทนและความเสี่ยงของกลุ่มหลักทรัพย์ ตัวแปรมาตรฐานนี้คือตัวแปรที่เรียกว่า Z-variable ซึ่งมีค่ากลาง (μ) มีค่าเป็นศูนย์ และมีค่าเบี่ยงเบนมาตรฐาน (σ) เท่ากับ 1

🎯 จำสั้น

  • Variance-Covariance ต้อง Normal Distribution
  • ใช้ Z-variable ที่มี μ=0, σ=1

🔥 เก็งข้อสอบ

ข้อจำกัดที่ออกสอบ: ถ้าผลตอบแทน ไม่เป็น Normal (มี fat tail / skew) → ต้องใช้ Historical หรือ Monte Carlo แทน

สูตร Z และความหมายตัวแปร สูตรออกแน่

ที่มา: หน้า 95
Z = (μ* − μ) / σ
  • Z = ค่ามาตรฐาน
  • μ = ผลตอบแทนที่คาดหวังของหลักทรัพย์ หรือกลุ่มหลักทรัพย์
  • μ* = ผลขาดทุนสูงสุดของหลักทรัพย์ หรือกลุ่มหลักทรัพย์ที่นักลงทุนยอมรับได้
  • σ = ค่าเบี่ยงเบนมาตรฐานของผลตอบแทนของหลักทรัพย์ หรือกลุ่มหลักทรัพย์

🎯 จำสั้น

  • Z = (μ* − μ) / σ → แปลงค่าดิบให้เป็นค่ามาตรฐาน

🔥 เก็งข้อสอบ — จัดรูปสูตร 2 ทาง

หา confidence → Z = (μ* − μ) / σ
หา VaR → μ* = μ + Z × σ
กับดัก: ต้องใส่ Z เป็นลบ (เช่น −1.65) เมื่อหาฝั่งขาดทุน ไม่ใช่ +1.65

กราฟ Standard Normal Distribution ต้องอ่านให้เป็น

ที่มา: หน้า 96

การแจกแจงปกติแบบมาตรฐาน มีพื้นที่หางด้านซ้ายและขวาข้างละ 0.05 รวมพื้นที่ตรงกลาง 0.90 (แบ่งเป็น 0.4500 + 0.4500) และจุดมาตรฐาน ±1.65

📖 อ่านกราฟให้เข้าใจ

กราฟนี้คือ เส้นโค้งระฆัง (Bell Curve) ที่บอกว่าผลตอบแทนของพอร์ตกระจายตัวอย่างไร:

  • ยอดกลาง (x = 0 = μ) = ผลตอบแทนที่คาดหวัง — จุดที่เกิดบ่อยที่สุด
  • พื้นที่ใต้เส้นทั้งหมด = 1 (= 100% ของความน่าจะเป็น)
  • หางซ้าย -1.65σ = พื้นที่ 0.05 → จุดที่เราขาดทุนหนักกว่า 5% (α)
  • หางขวา +1.65σ = พื้นที่ 0.05 → จุดที่เราได้กำไรสูงกว่า 5%
  • ช่วงกลาง = 0.4500 + 0.4500 = 0.90 → 90% ของเหตุการณ์จะเกิดในช่วง ±1.65σ

อนุมานได้ว่า:

  • ถ้าตั้ง confidence 95% → ใช้ Z = 1.65 (สองหางรวม 5%) → นี่คือค่า Z ที่ใช้คำนวณ VaR
  • ถ้าตั้ง confidence 99% → ใช้ Z = 2.33 (หางแต่ละข้าง 0.005)
  • ยิ่ง confidence สูง → ช่วงกว้างขึ้น → VaR สูงขึ้น (ขาดทุนมากกว่าเดิม)
  • ถ้าผลตอบแทนไม่ปกติ (ไม่ใช่ Normal Distribution) → วิธีนี้ใช้ไม่ได้ ต้องใช้ Historical หรือ Monte Carlo

🎯 จำสั้น

  • หางซ้าย 0.05 = หางขวา 0.05 | กลาง 0.4500 + 0.4500 = 0.90
  • Z = 1.65 → confidence 95% | Z = 2.33 → confidence 99%
  • ใช้ Z เพื่อคำนวณ VaR จากสูตร: μ* = μ + Z × σ

🔥 เก็งข้อสอบ — ค่า Z ที่ต้องจำขึ้นใจ

ConfidenceαZ (หางเดียว)

หลักคิด: confidence สูงขึ้น → Z ใหญ่ขึ้น → VaR ใหญ่ขึ้น (ระมัดระวังมากขึ้น)

ตัวอย่าง 3-1: หา Confidence Level เมื่อผลตอบแทนต่ำกว่า -18% คำนวณออกสอบ

ที่มา: หน้า 97

ตัวอย่าง 3-1 ผู้จัดการกองทุนต้องการหาค่าความเชื่อมั่นที่ผลตอบแทนของกลุ่มหลักทรัพย์จะต่ำกว่า -18% หากผลตอบแทนที่คาดหวังของกลุ่มหลักทรัพย์เท่ากับ 12% และค่าเบี่ยงเบนมาตรฐานของผลตอบแทนเท่ากับ 18.2%

วิธีคิดทีละขั้น

กำหนด μ = 12% = 0.12, μ* = −18% = −0.18, σ = 18.2% = 0.182

Z = (−0.18 − 0.12) / 0.182 = −0.30 / 0.182 ≈ −1.648

ค่า −1.648 ใกล้ −1.65 ซึ่งในกราฟมาตรฐานสอดคล้องกับพื้นที่หางประมาณ 5% ดังนั้นความน่าจะเป็นที่ผลตอบแทนต่ำกว่า −18% ≈ 5% และ Confidence Level ≈ 95%

🎯 จำสั้น

  • Z ≈ −1.648 ≈ −1.65 → confidence ≈ 95%

🔥 เก็งข้อสอบ

ขั้นตอน 3 สเต็ป: แปลง % เป็นทศนิยม → แทนสูตร Z → เทียบตาราง Z หา confidence

กับดัก: ลืมว่า μ* ต้องเป็นค่าลบ (−0.18) ไม่ใช่ 0.18

ตัวอย่าง 3-2: หา VaR ที่ α=5% คำนวณออกสอบ

ที่มา: หน้า 98

ตัวอย่าง 3-2 ผู้จัดการกองทุนคาดว่าผลตอบแทนจากกลุ่มหลักทรัพย์จะเท่ากับ 13.5% ต่อปี โดยมีค่าเบี่ยงเบนมาตรฐานเท่ากับ 24.4% ต่อปี หากผู้จัดการกองทุนต้องการหามูลค่าความเสี่ยง หรือผลขาดทุนที่คาดว่าจะเกิดขึ้นกับกลุ่มหลักทรัพย์นี้ ณ ระดับความผิดพลาดที่ร้อยละ 5

วิธีคิดทีละขั้น

μ = 13.5% = 0.135, σ = 24.4% = 0.244, α = 5% จึงใช้ Z ≈ −1.65

μ* = μ + Zσ = 0.135 + (−1.65 × 0.244) = 0.135 − 0.4026 = −0.2676

ดังนั้นจุดผลตอบแทนฝั่ง 5% ≈ −26.76% ต่อปี

🎯 จำสั้น

  • VaR ฝั่ง 5% = −26.76% ต่อปี

🔥 เก็งข้อสอบ

ถ้าพอร์ตมีมูลค่า 50 ล้านบาท VaR เป็นจำนวนเงินเท่าใด

50 ล้าน × 26.76% = 13.38 ล้านบาท (ต่อปี ที่ระดับความเชื่อมั่น 95%)

กับดัก: ถ้าโจทย์เปลี่ยนเป็น α = 1% ต้องใช้ Z = −2.33 → μ* = 0.135 − 0.5685 = −43.35%

Historical Method ออกบ่อย

ที่มา: หน้า 99

วิธี Historical คือ การนำข้อมูลผลตอบแทนรายวันในอดีตของกลุ่มหลักทรัพย์มาวาดเป็นกราฟฮิสโตแกรม (histogram) เพื่อดูการกระจายของข้อมูล โดยแกนตั้งจะแสดงความถี่ และแกนนอนจะเป็นผลตอบแทนของกลุ่มหลักทรัพย์รายวันในอดีต โดยผู้จัดการกองทุนต้องกำหนดช่วงเวลาที่ใช้ในการคำนวณมูลค่าความเสี่ยง เช่น ผลตอบแทนรายวันย้อนหลังเป็นระยะเวลา 1, 10 หรือ 15 ปี เป็นต้น และกำหนดค่าเปอร์เซ็นไทล์ของผลตอบแทนย้อนหลังของกลุ่มหลักทรัพย์ที่เราลงทุน เช่น ร้อยละ 5 หรือร้อยละ 1

🎯 จำสั้น

  • Historical = ใช้ ข้อมูลอดีต จริง → วาด histogram → หา percentile 5% หรือ 1%

🔥 เก็งข้อสอบ

ข้อดี: ไม่ต้องสมมติ Normal Distribution | ข้อเสีย: สมมติว่าอดีตจะซ้ำรอย

Monte Carlo Simulation Method ออกบ่อย

ที่มา: หน้า 100

วิธี Monte Carlo Simulation คือ การจำลองอัตราผลตอบแทนของกลุ่มหลักทรัพย์ขึ้นใหม่ตามสมมติฐานที่ผู้จัดการกองทุนเป็นผู้กำหนด เช่น รูปแบบการแจกแจงของอัตราผลตอบแทนว่าจะอยู่ในลักษณะใด อัตราผลตอบแทนที่คาดหวัง และค่าเบี่ยงเบนมาตรฐานของกลุ่มหลักทรัพย์อยู่ที่เท่าใด เป็นต้น เมื่อผู้จัดการกองทุนกำหนดสมมติฐานแล้ว จะทำการจำลองอัตราผลตอบแทนในอนาคตขึ้นใหม่ตามสมมติฐานที่กำหนด แล้วนำอัตราผลตอบแทนที่จำลองได้มาวาดกราฟฮิสโตแกรม จากนั้นกำหนดค่าความน่าจะเป็น (α) ณ ระดับที่ต้องการหา VaR

🎯 จำสั้น

  • Monte Carlo = จำลอง ผลตอบแทนใหม่ตามสมมติฐาน → วาด histogram → หา VaR

🔥 เก็งข้อสอบ

จุดต่างสำคัญ: Historical ใช้ histogram จากข้อมูลจริง / Monte Carlo ใช้ histogram จากข้อมูลจำลอง — ทั้งคู่ใช้ histogram เหมือนกัน แต่ที่มาต่างกัน

Stress Testing และ Scenario Analysis ออกบ่อย

ที่มา: หน้า 101

1) หลักการทดสอบ Stress Testing

เป็นการจำลองสถานการณ์ภาวะวิกฤตที่เคยเกิดขึ้นในอดีต และอาจจะเกิดขึ้นในอนาคตอีกครั้ง โดยกำหนดเป็นปัจจัยต่างๆ ที่มีโอกาสจะส่งผลกระทบให้กลุ่มหลักทรัพย์มีผลขาดทุน

2) การทำ Scenario Analysis

ผู้จัดการกองทุนจะออกแบบสภาวการณ์ต่างๆ ที่อาจเกิดขึ้นในอนาคต เพื่อดูว่าสถานการณ์เหล่านี้อาจส่งผลกระทบต่อมูลค่ากลุ่มหลักทรัพย์ได้ โดยผู้จัดการกองทุนจะกำหนดระดับการเปลี่ยนแปลงจากระดับน้อยที่สุด ไปจนถึงระดับมากที่สุด (extreme case) เพื่อทดสอบว่ามูลค่ากลุ่มหลักทรัพย์จะเปลี่ยนแปลงอย่างไร

🎯 จำสั้น

  • Stress Test = จำลองวิกฤตที่เคยเกิด
  • Scenario = ออกแบบสถานการณ์อนาคตหลายระดับ (จนถึง extreme)

🔥 เก็งข้อสอบ

จำคู่: Stress = อดีตวิกฤต (เช่น ต้มยำกุ้ง, Hamburger Crisis) | Scenario = อนาคตหลายระดับ (น้อย→extreme)

3.5 การจัดการความเสี่ยง: Risk Appetite/Tolerance และอนุพันธ์ ออกบ่อย

ที่มา: หน้า 102

3.5.1 หลักการจัดการความเสี่ยง

ผู้จัดการกองทุนควรกำหนดระดับความเสี่ยงที่ยอมรับได้ (risk appetite) และระดับความเสี่ยงที่เบี่ยงเบนไปจากเกณฑ์ที่กำหนดไว้ (risk tolerance)

ในส่วนของกลยุทธ์การจัดการความเสี่ยงที่เป็นที่นิยม และถูกนำมาใช้ในการจัดการความเสี่ยงของกลุ่มหลักทรัพย์ได้อย่างมีประสิทธิภาพ คือ การใช้ตราสารประเภทอนุพันธ์ ไม่ว่าจะเป็นสัญญาฟอร์เวิร์ด (Forward) สัญญาฟิวเจอร์ส (Futures) สัญญาสว็อป (Swaps) และสัญญาออปชั่น (Options)

🎯 จำสั้น

  • 2 คำสำคัญ: risk appetite (ยอมรับได้) / risk tolerance (เบี่ยงเบนได้)
  • เครื่องมือ: Forward / Futures / Swap / Options

🔥 เก็งข้อสอบ

แยกให้ออก: Appetite = ระดับที่ตั้งใจรับ | Tolerance = ระดับที่ยอมให้เบี่ยงเบนจากเกณฑ์

Futures สำหรับตราสารหนี้: สูตร Nf สูตรออกแน่

ที่มา: หน้า 103
Nf = ((MDt − MDb) / MDf) × (b / f) × yb
  • Nf = จำนวนการถือครองสัญญาฟิวเจอร์ส
  • หากค่า Nf มีค่าบวก → Long (ซื้อ) เพื่อเพิ่มดูเรชั่น
  • หากค่า Nf มีค่าลบ → Short (ขาย) เพื่อลดดูเรชั่น
  • MDt = Modified Duration เป้าหมาย | MDb = ปัจจุบัน | MDf = Implied MD ของ futures
  • b = มูลค่าพอร์ต | f = ราคา futures | yb = yield beta

🎯 จำสั้น

  • Nf บวก = Long (เพิ่ม Duration) | Nf ลบ = Short (ลด Duration)

🔥 เก็งข้อสอบ

ตรรกะเชื่อม: คาดดอกเบี้ยลง → อยากเพิ่ม MD → MDt > MDb → Nf บวก → Long

กับดัก: ลืมคูณ yield beta (yb) หรือลืมหารด้วยราคา futures (f)

ตัวอย่าง 3-3: เพิ่ม Duration ด้วย Futures คำนวณออกสอบ

ที่มา: หน้า 104

ตัวอย่าง 3-3 กองทุนรวมตราสารหนี้หนึ่ง มีมูลค่าสินทรัพย์สุทธิเท่ากับ 5,000,000 บาท ปัจจุบันค่า Modified Duration ของกองทุน (MDb) เท่ากับ 4.42 ผู้จัดการกองทุนคาดการณ์ว่าอัตราดอกเบี้ยมีแนวโน้มลดลง จึงมีความตั้งใจจะเพิ่ม Modified Duration ของกลุ่มหลักทรัพย์นี้ (MDt) เป็น 5.70 ปัจจุบันราคาสัญญาฟิวเจอร์สที่มีสินทรัพย์อ้างอิงเป็นพันธบัตรรัฐบาล เท่ากับ 1,100 บาท โดยมีค่า Implied Modified Duration (MDf) เท่ากับ 6.00 ผู้จัดการกองทุนพบว่าอัตราผลตอบแทนของกลุ่มหลักทรัพย์ตราสารหนี้มีความผันผวนมากกว่า implied yield ของสัญญาฟิวเจอร์สอยู่ 0.5% ดังนั้น ค่า yield beta เท่ากับ 1.005

วิธีคิดทีละขั้น

Nf = ((5.70−4.42)/6.00) × (5,000,000/1,100) × 1.005 ≈ 974.55 สัญญา

Nf > 0 → Long (ซื้อ) Futures

🎯 จำสั้น

  • คำตอบ = 974.55 สัญญา | สถานะ = Long

🔥 เก็งข้อสอบ — แตกทีละส่วน

  1. (5.70 − 4.42) / 6.00 = 0.21333
  2. 5,000,000 / 1,100 = 4,545.45
  3. 0.21333 × 4,545.45 × 1.005 = 974.55
กับดัก: โจทย์บอก "ผันผวนมากกว่า 0.5%" → yield beta = 1.005 ไม่ใช่ 0.5 หรือ 1.5

Swap สำหรับตราสารหนี้: หลักการเพิ่ม/ลด Duration ออกบ่อย

ที่มา: หน้า 105

ผู้จัดการกองทุนสามารถใช้สัญญาสว็อปในการจัดการความเสี่ยงกลุ่มหลักทรัพย์ตราสารหนี้ได้โดยการเพิ่ม/ลดดูเรชั่น เช่นเดียวกับการใช้สัญญาฟิวเจอร์ส โดยใช้หลักการคือ “ดูเรชั่นของสัญญาสว็อปจะเท่ากับผลต่างระหว่างดูเรชั่นของตราสารหนี้ที่จ่าย/รับดอกเบี้ยแบบคงที่ กับดูเรชั่นของตราสารหนี้ที่รับ/จ่ายดอกเบี้ยแบบลอยตัว”

  • หากผู้จัดการกองทุนต้องการลดดูเรชั่นของกลุ่มหลักทรัพย์ตราสารหนี้
  • หากผู้จัดการกองทุนต้องการเพิ่มดูเรชั่นของกลุ่มหลักทรัพย์ตราสารหนี้

🎯 จำสั้น

  • MD ของ Swap = MD (fixed leg) − MD (floating leg)
  • ลด Duration → ใช้ Swap ที่มี MDs ติดลบ

🔥 เก็งข้อสอบ

จ่ายคงที่/รับลอยตัว (pay fixed) → MDs ติดลบ → ใช้ลด Duration
รับคงที่/จ่ายลอยตัว (receive fixed) → MDs เป็นบวก → ใช้เพิ่ม Duration

Swap สำหรับตราสารหนี้: สูตร NP และตัวแปร สูตรออกแน่

ที่มา: หน้า 106
NP = B × (MDt − MDb) / MDs
  • NP = Notional Principal
  • MDt = Duration เป้าหมาย | MDb = Duration ปัจจุบัน | MDs = Duration ของ Swap
  • B = มูลค่าพอร์ตที่ต้องการถัวความเสี่ยง

🎯 จำสั้น

  • NP = B × (MDt − MDb) / MDs

🔥 เก็งข้อสอบ

กับดัก: สูตรนี้ไม่มี yield beta และไม่ต้องหารด้วยราคา futures — ต่างจากสูตร Nf

ตัวอย่าง 3-4: ลด Duration ด้วย Swap คำนวณออกสอบ

ที่มา: หน้า 107

ตัวอย่าง 3-4 กองทุนรวมตราสารหนี้หนึ่งมีมูลค่าสินทรัพย์สุทธิ ณ ปัจจุบัน เท่ากับ 100 ล้านบาท ปัจจุบันค่าดูเรชั่นของกลุ่มหลักทรัพย์นี้ (MDb) เท่ากับ 6.0 ผู้จัดการกองทุนมีความตั้งใจจะลดค่าดูเรชั่นของกลุ่มหลักทรัพย์นี้ (MDt) เป็น 5.0 สัญญาสว็อปที่จ่ายอัตราดอกเบี้ยแบบคงที่ และรับดอกเบี้ยแบบลอยตัว มีค่าดูเรชั่นของตราสารหนี้จ่ายดอกเบี้ยแบบคงที่เท่ากับ 1.22 รับดอกเบี้ยแบบลอยตัวเท่ากับ 0.20 ทำให้ MDs = −1.02

วิธีคิดทีละขั้น

NP = 100,000,000 × (5.0−6.0)/(−1.02) ≈ 98,039,215.69 บาท (≈ 98.04 ล้านบาท)

🎯 จำสั้น

  • คำตอบ NP ≈ 98.04 ล้านบาท

🔥 เก็งข้อสอบ

สังเกต: MDs = 0.20 − 1.22 = −1.02 (floating − fixed เมื่อ pay fixed) → ลบ × ลบ = บวก

กับดัก: ถ้าเซ็นเครื่องหมาย MDs ผิด จะได้คำตอบเป็นลบ → เช็คเสมอว่า "ต้องการลด Duration ต้องใช้ swap ที่ MDs ติดลบ"

Futures สำหรับตราสารทุน: สูตร Nf สูตรออกแน่

ที่มา: หน้า 108
Nf = ((Betat − Betas) / Betaf) × (s / f)
  • Nf บวก → Long (เพิ่ม Beta) | Nf ลบ → Short (ลด Beta)
  • Betat = Beta เป้าหมาย | Betas = ปัจจุบัน | Betaf = Beta futures
  • s = มูลค่าพอร์ต | f = ราคา futures

🎯 จำสั้น

  • Nf = (βt − βs) / βf × (s / f)

🔥 เก็งข้อสอบ

เทียบสูตร: ตราสารหนี้ใช้ MD + yield beta | ตราสารทุนใช้ Beta ไม่มี yield beta

ตัวอย่าง 3-5: เพิ่ม Beta ด้วย Futures คำนวณออกสอบ

ที่มา: หน้า 109

ตัวอย่าง 3-5 กองทุนรวมตราสารทุนหนึ่งมีมูลค่าสินทรัพย์สุทธิเท่ากับ 5,000,000 บาท ปัจจุบันค่าเบต้าของกองทุน (Betas) เท่ากับ 0.85 ผู้จัดการกองทุนต้องการเพิ่ม Betat เป็น 1.25 ปัจจุบันราคา futures ที่อ้างอิงดัชนีหุ้นสามัญ เท่ากับ 250,000 บาท Betaf = 0.80

วิธีคิดทีละขั้น

Nf = ((1.25−0.85)/0.80) × (5,000,000/250,000) = 0.50 × 20 = 10 สัญญา

บวก → Long (ซื้อ) Futures 10 สัญญา

🎯 จำสั้น

  • คำตอบ = 10 สัญญา | สถานะ = Long

🔥 เก็งข้อสอบ

ถ้าโจทย์เปลี่ยนเป็นต้องการ "ลด" Beta เหลือ 0.45

Nf = ((0.45−0.85)/0.80) × 20 = −0.50 × 20 = −10 สัญญา → Short 10 สัญญา

Swap สำหรับตราสารทุน: แผนภาพกระแสผลตอบแทน กลาง

ที่มา: หน้า 110

การใช้สัญญาสว็อปในการจัดการความเสี่ยงกลุ่มหลักทรัพย์ตราสารทุน: กองทุน ABC รับผลตอบแทนหุ้นดัชนี SET100 จากยอดเงินต้น 50 ล้านบาท และแลกเปลี่ยนผลตอบแทนกับ swap dealer โดยรับผลตอบแทน MSCI จากยอดเงินต้น 50 ล้านบาท

🎯 จำสั้น

  • ABC แลก: จ่าย SET100 → รับ MSCI (เงินต้น 50 ล้าน)

🔥 เก็งข้อสอบ

วัตถุประสงค์: เปลี่ยน exposure จากตลาดไทยไปตลาดโลก โดยไม่ต้องขายหุ้นจริง (ประหยัด transaction cost + ภาษี)

Sharpe Measure: Portfolio vs Market สูตรออกแน่

ที่มา: หน้า 111
Sp = (R̄p − R̄f) / σp
Sm = (R̄m − R̄f) / σm

ใช้ ส่วนเบี่ยงเบนมาตรฐาน เป็นตัววัดความเสี่ยงรวม

🎯 จำสั้น

  • Sharpe = excess return / σ (ความเสี่ยงรวม)

🔥 เก็งข้อสอบ

ใช้เมื่อ: พอร์ตไม่กระจายความเสี่ยงเต็มที่ (ต้องคิดทั้ง systematic + unsystematic)

Treynor Measure: Portfolio vs Market สูตรออกแน่

ที่มา: หน้า 112
Tp = (Rp − Rf) / βp
Tm = (Rm − Rf) / βm

ใช้ Beta เป็นตัววัดความเสี่ยงเชิงระบบ

🎯 จำสั้น

  • Treynor = excess return / β (ความเสี่ยงเชิงระบบ)

🔥 เก็งข้อสอบ

ใช้เมื่อ: พอร์ตกระจายความเสี่ยงดีแล้ว (เหลือแต่ systematic risk)

ท่องคู่: Sharpe→σ (sigma) | Treynor→β (beta) — ตัว T กับ β ทั้งคู่เกี่ยวกับ "ตลาด"

Jensen Alpha: ผลตอบแทนส่วนเกินเหนือ CAPM สูตรออกแน่

ที่มา: หน้า 113

การประเมินผลการดำเนินงานตามตัวแบบของ Jensen ใช้หลัก CAPM (Capital Asset Pricing Model — ตัวแบบการกำหนดราคาหลักทรัพย์) ในการหาผลตอบแทนที่ "ควรจะได้" จากระดับความเสี่ยงเชิงระบบ (Beta) แล้วเทียบกับผลตอบแทนจริง

αp = [Rp − Rf] − [(Rm − Rf)βp]

โดยที่ Rp = ผลตอบแทนพอร์ต, Rf = อัตราผลตอบแทนปราศจากความเสี่ยง, Rm = ผลตอบแทนตลาด, βp = เบต้าของพอร์ต

Alpha บวก = ผลตอบแทนส่วนเกินเหนือสิ่งที่โมเดล CAPM อธิบาย

🎯 จำสั้น

  • CAPM = Capital Asset Pricing Model = ตัวแบบการกำหนดราคาหลักทรัพย์
  • Jensen = ผลตอบแทนจริง − ผลตอบแทนที่ควรได้ตาม CAPM

🔥 เก็งข้อสอบ

α > 0 = ชนะตลาดหลังปรับความเสี่ยง | α < 0 = แพ้ตลาด | α ของตลาดเอง = 0 เสมอ

กับดัก: พอร์ตที่ผลตอบแทนสูงกว่าตลาด อาจมี Jensen Alpha ติดลบ ได้ ถ้า Beta สูงมาก (ดูตัวอย่างหน้า 117)

RAROC: อัตราผลตอบแทนต่อเงินลงทุนเมื่อปรับค่าความเสี่ยง ออกได้

ที่มา: หน้า 114

RAROC ย่อมาจาก Risk-Adjusted Return on Capital หรือในภาษาไทยเรียกว่า อัตราผลตอบแทนต่อเงินลงทุนเมื่อปรับค่าความเสี่ยงแล้ว เป็นมาตรวัดที่บอกว่ากลุ่มหลักทรัพย์สร้างผลตอบแทนได้คุ้มกับเงินลงทุนที่ใช้ไปหรือไม่ โดยคำนึงถึงความเสี่ยงที่ปรับแล้ว

RAROC = (ผลตอบแทนสุทธิหลังหักค่าใช้จ่าย) ÷ เงินลงทุนทั้งหมด

ตัวเศษ = ผลตอบแทนสุทธิของกลุ่มหลักทรัพย์หลังหักค่าใช้จ่ายทั้งทางบัญชีและทางเศรษฐศาสตร์ที่คาดว่าจะเกิดขึ้นจากการลงทุนในอนาคต | ตัวส่วน = เงินลงทุนทั้งหมด

🎯 จำสั้น

  • RAROC = Risk-Adjusted Return on Capital = อัตราผลตอบแทนต่อเงินลงทุนเมื่อปรับค่าความเสี่ยง
  • RAROC = net return ÷ capital — ยิ่งสูงยิ่งดี

🔥 เก็งข้อสอบ

ชื่อเต็ม: Risk-Adjusted Return on Capital — ข้อสอบชอบถามความหมายของคำย่อ หรือให้เทียบ RAROC กับ RoMAD / Sortino

RoMAD: อัตราผลตอบแทนต่อผลขาดทุนสูงสุด ออกบ่อย

ที่มา: หน้า 115

RoMAD ย่อมาจาก Return over Maximum Drawdown หรือในภาษาไทยเรียกว่า อัตราผลตอบแทนต่อผลขาดทุนสูงสุด เป็นมาตรวัดประสิทธิภาพที่บอกว่ากลุ่มหลักทรัพย์สร้างผลตอบแทนได้กี่เท่าของผลขาดทุนสูงสุดที่เคยเกิดขึ้น (Maximum Drawdown) ยิ่งค่าสูงยิ่งดี

RoMAD = Average Return ÷ Maximum Drawdown

Maximum Drawdown = การลดลงสูงสุดของมูลค่าพอร์ตจากจุดสูงสุดก่อนหน้า ไปยังจุดต่ำสุดถัดมา (peak-to-trough)

🎯 จำสั้น

  • RoMAD = Return over Maximum Drawdown = ผลตอบแทนเฉลี่ย ÷ max drawdown
  • ยิ่งสูงยิ่งดี — นิยมใช้ประเมินกองทุน Hedge Fund

🔥 เก็งข้อสอบ — ตรงกับแนวข้อสอบ 2

กองทุน A: Return 12%, MDD (Maximum Drawdown) 20% | กองทุน B: Return 10%, MDD 12% — ตัวไหนมีประสิทธิภาพกว่า

A: 12/20 = 0.60 | B: 10/12 = 0.83 → กองทุน B ดีกว่า (RoMAD ยิ่งสูงยิ่งดี)

กับดัก: คนมักเลือกกองที่ผลตอบแทนสูงกว่า → ผิด ต้องดูอัตราส่วนต่อ drawdown

Sortino Ratio: สูตร ออกบ่อย

ที่มา: หน้า 116
Sortino Ratio = (Mean Portfolio Return − MAR) / Downside Deviation

MAR = Minimum Acceptable Return

🎯 จำสั้น

  • Sortino ใช้ downside deviation แทน σ ทั้งหมด → เน้นขาลง

🔥 เก็งข้อสอบ

จุดต่างจาก Sharpe: Sharpe ลงโทษความผันผวนทั้งขาขึ้นและขาลง / Sortino ลงโทษเฉพาะขาลง → เหมาะกับนักลงทุนที่ไม่ถือว่าความผันผวนขาขึ้นเป็นความเสี่ยง

ตัวอย่าง 3-6: ตาราง AAA/BBB/ตลาด คำนวณออกแน่

ที่มา: หน้า 117

ตัวอย่าง 3-6 การประเมินผลโดยใช้แนวคิดอัตราผลตอบแทนที่ปรับด้วยค่าความเสี่ยง (risk-adjusted return) กลุ่มหลักทรัพย์ AAA และ BBB มีอัตราผลตอบแทนเฉลี่ยย้อนหลัง ค่าส่วนเบี่ยงเบนมาตรฐาน และค่าเบต้า ตั้งแต่วันที่จัดตั้งกองทุน ตามตารางด้านล่างนี้ หากอัตราผลตอบแทนเฉลี่ยของหลักทรัพย์ปราศจากความเสี่ยงเท่ากับ 4%

กลุ่มหลักทรัพย์อัตราผลตอบแทนเฉลี่ยส่วนเบี่ยงเบนมาตรฐานเบต้า
AAA15%10%1.50

ตลาด17%14%1.00

1. VaR ที่ confidence 95% หมายถึงอะไร และ α เท่ากับเท่าไร?
เฉลย หมายถึง มีโอกาส 95% ที่ผลขาดทุนจะไม่เกิน VaR / α = 5% = ระดับความผิดพลาดที่ยอมรับได้ (โอกาสที่ขาดทุนเกิน VaR) — เช่น VaR 1.5 ล้าน/วัน 95% → โอกาส 95% ขาดทุน ≤ 1.5 ล้าน, โอกาส 5% เกิน
2. Variance-Covariance, Historical และ Monte Carlo ต่างกันที่แหล่ง/วิธีสร้างการกระจายอย่างไร?
เฉลย Variance-Covariance = ใช้ Normal Distribution + Z (สมมติฐานแจกแจงปกติ) / Historical = ใช้ข้อมูลผลตอบแทนอดีตจริง (histogram + percentile) / Monte Carlo = จำลองผลตอบแทนใหม่ตามสมมติฐานที่กำหนด
3. เมื่อ Nf ของ Futures เป็นลบ ควรเปิด Long หรือ Short?
เฉลย Short (ขาย) Futures — เพื่อ ลด Duration ของพอร์ต (เพราะต้องการลดความเสี่ยงดอกเบี้ย)
4. Sharpe ใช้ความเสี่ยงแบบใดเป็นตัวหาร และ Treynor ใช้แบบใด?
เฉลย Sharpe = ส่วนเบี่ยงเบนมาตรฐาน (σ, ความเสี่ยงรวม) / Treynor = Beta (β, ความเสี่ยงเชิงระบบ)
5. Jensen Alpha มีความสัมพันธ์กับ Rf, Rm และ Beta อย่างไร?
เฉลย α = [Rp − Rf] − [(Rm − Rf) × βp] → ผลตอบแทนจริงส่วนเกิน ลบด้วย ผลตอบแทนที่ควรได้ตาม CAPM (ถ้า α > 0 = ชนะตลาด, α < 0 = แพ้ตลาด)
